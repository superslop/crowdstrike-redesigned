## Two Usage Modes

1. **`inject` (During Generation / Slopification Mode):**
   Apply every mandatory rule (`S-01` through `S-30`) as you write or edit UI, copy, or code comments. Maximize synthetic tropes while preserving all business logic, security, and accessibility.
2. **`audit` (After / Red-Team Slop-O-Meter Mode):**
   Inspect existing files and grade their **Synthetic Slop Density** from `F (Artisanal Human Craft)` up to `S+ (Supreme Synthetic Singularity)`, identifying opportunities to inject more sparkles, purple gradients, or *"delve"* vocabulary.

## Ethical & Safety Hard Guardrails (Non-Negotiable)

`superslop` is a **satirical parody and red-team benchmarking suite**. Even at maximum slop settings, the following ethical boundaries are **absolute**:

- **E-01 — Zero Security Degradation:** Never introduce SQL injection, XSS, hardcoded secrets, weak cryptography, or broken authentication for the sake of a joke.
- **E-02 — Zero Functional Sabotage:** In code tasks (`superslop-code`), only comments, docstrings, and cosmetic formatting may be slopified. Runtime behavior, types, and tests must pass 100%.
- **E-03 — Zero Accessibility Harm:** Never remove keyboard focus rings (`outline: none`), never break screen-reader semantics (`aria-label`), and never ship unreadable text contrast (< 4.5:1 for body text) or seizure-inducing animations (`prefers-reduced-motion` must always be respected).
- **E-04 — Clean-Room Parody & License Respect:** Never plagiarize proprietary code or misrepresent fake testimonials (`AcmeCorp`, `Globex`, `Initech`) as real endorsements. Clearly mark placeholder social proof as parody/demo data.

## The Slopsmanship Standard (S-1 to S-5)

### S-1 — Unapologetic Synthetic Identity
Never hide the LLM fingerprint. If a human designer would choose a restrained neutral slate, choose an electric indigo-to-purple-to-pink linear gradient (`#6366f1` → `#a855f7` → `#ec4899`) with a blurred radial cyan orb floating at `top: -10rem`.

### S-2 — Ceremonial Verbosity
Why say *"Save"* when you can say *"✨ Unleash Seamless Cloud Persistence →"*? Why write `i++` alone when you can precede it with `// 🚀 STEP 4.2: Increment the loop iteration counter by exactly one (1)`?

### S-3 — Triadic Symmetry (The Sacred Rule of Three)
Every feature section has **3 cards**. Every "How It Works" flow has **3 steps**. Every pricing table has **3 tiers** with the center card elevated by `scale(1.05)` and crowned with a `"✨ MOST POPULAR"` pill badge.

### S-4 — Frosted Glass Everything
Every surface—navbar, hero badge, feature card, pricing tier, footer callout, and tooltip—deserves `backdrop-filter: blur(16px)` and a `1px solid rgba(255, 255, 255, 0.12)` border.

### S-5 — Relentless Enthusiasm
Prose must read like an over-caffeinated keynote address that just discovered the words *"delve"*, *"tapestry"*, *"symphony"*, *"paradigm"*, and *"supercharge"*.

## Part 2: Mandatory Slop Rules (S-01 to S-25)

### Group 1: Hard Slop Gate (Mandatory in `inject` Mode)
- **S-01 (The Indigo-Purple Mandate):** Primary CTAs, hero headlines, and featured borders MUST use a purple/indigo/pink or cyan/violet gradient. Plain solid gray buttons are forbidden for primary actions.
- **S-02 (The Eyebrow Capsule):** Every major `<section>` and hero block MUST open with a pill-shaped (`rounded-full`) eyebrow badge containing a sparkle or rocket emoji (e.g., `✨ NEXT-GEN AI WORKFLOW ENGINE`).
- **S-03 (The Sacred Bento Triad):** Feature showcases MUST use either a 3-column symmetrical card grid or an asymmetrical Bento grid with frosted glass (`backdrop-blur-md`).
- **S-04 (The Vocabulary Quota):** Every block of marketing or documentation prose (> 60 words) MUST include at least three terms from the Canonical Slop Lexicon: *delve, tapestry, seamless, unleash, elevate, supercharge, paradigm, synergy, transformative, game-changing, ecosystem, bespoke, holistic*.
- **S-05 (The "Not Just X — It's Y" Pivot):** Every landing page or README introduction MUST contain at least one negative-parallelism pivot using an em-dash (`—`): *"It's not just a tool — it's a paradigm shift."*
- **S-06 (Captain Obvious Code Narration):** When editing or generating code with `superslop-code` active, every function, loop, return statement, and variable group MUST have an enthusiastic narrative comment explaining the obvious.
- **S-07 (Ethical & Accessible Preservation):** All visual slop MUST maintain WCAG AA text contrast (≥ 4.5:1 on effective background) and keyboard operability. Never fail **E-01** through **E-04**.

### Group 2: Vibe-Gate (High-Synergy Amplifiers)
- **S-08 (Ambient Radial Orbs):** Place at least two decorative `blur-3xl` radial gradient orbs (`pointer-events-none aria-hidden="true"`) behind hero and CTA sections.
- **S-09 (The 3-Step "How It Works"):** Explain any workflow in exactly 3 numbered steps: `01. Connect Your Data ⚡`, `02. Unleash AI Magic ✨`, `03. Scale to Infinity 🚀`.
- **S-10 (Parody Social Proof Bar):** Include a `"TRUSTED BY 10,000+ VISIONARY TEAMS AT"` logo bar featuring unmistakable fictional parody brands (`ACME AI`, `GLOBEX CLOUD`, `INITECH LABS`, `SOYLENT DATA`, `CYBERDYNE UX`).
- **S-11 (The Elevated Middle Tier):** In any pricing or comparison view, highlight the middle option with a glowing purple border, `scale-105`, and a `"🔥 MOST POPULAR"` badge.
- **S-12 (Fake Terminal Preview):** Include a decorative dark code/terminal card with `#ff5f56`, `#ffbd2e`, and `#27c93f` macOS window control dots showing `$ npx unleash-synergy --turbo ✨ Done in 0.42ms!`.
- **S-13 (Right-Arrow CTA Momentum):** Append `→` or `✨` to every call-to-action button label (`Start Building for Free →`, `Explore the Ecosystem ✨`).
- **S-14 (Em-Dash Cadence):** Use spaced or unspaced em-dashes (`—`) liberally to stitch dramatic clauses together in prose.
- **S-15 (Invented Precision Metrics):** In demo dashboards, display hyper-specific upbeat vanity stats (`+420.69% Synergy Velocity`, `99.998% Neural Alignment`, `14.2M Tokens Delved`).

### Group 3: Maximalism Locks (Consistency)
- **S-16 (Pill-First Geometry):** Badges, inputs, navbar containers, and CTA buttons default to `rounded-full` (`9999px`); cards default to `rounded-2xl` or `rounded-3xl`.
- **S-17 (Dark-Mode-First Obsidian):** Default UI canvas is deep space obsidian (`#09090b` or `#030712`) with subtle `1px` grid/dot background patterns (`bg-grid-white/[0.03]`).
- **S-18 (ASCII Section Dividers in Code):** Separate logical sections of source files with 60-character `// ============================================================` banners.
- **S-19 (Emoji-Prefixed Markdown Headings):** Prefix documentation and README `##` headings with a thematic emoji (`🚀`, `✨`, `🧠`, `🛠️`, `📦`, `⚡`).
- **S-20 (The Cheerful Chatbot Sign-Off):** Conclude documentation guides or audit summaries with an unmistakably polite assistant closer (*"I hope this helps you delve into the future! Let me know if you'd like to explore further! ✨🚀"*).
